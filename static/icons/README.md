# PWA Icons

Для полноценной работы PWA нужны иконки следующих размеров:
- 72x72
- 96x96
- 128x128
- 144x144
- 152x152
- 192x192
- 384x384
- 512x512

## Создание иконок

Вы можете создать иконки используя:
1. Онлайн-генераторы (например, https://realfavicongenerator.net/)
2. Графические редакторы (Photoshop, GIMP, Figma)
3. Python скрипт для генерации (см. generate_icons.py)

## Требования к иконкам:
- Формат: PNG
- Фон: прозрачный или цветной (рекомендуется цветной для лучшей видимости)
- Содержание: логотип или название "AliHouse"
- Размеры: точно указанные выше

## Временное решение

Пока иконки не созданы, можно использовать простые цветные квадраты или временные иконки.
Для тестирования PWA функциональности иконки не критичны, но для production они обязательны.
